# 第一章：计算机入门

如果你平时主要使用手机，第一次接触电脑上的文件、安装包或命令终端，本章可以作为起点。从键盘与鼠标开始，把后续学习编程会用到的基本知识按顺序连接起来。

## 为什么学

开发软件会反复涉及输入文字、寻找文件、安装工具、阅读资料和保存修改。先熟悉这些操作，遇到问题时就更容易描述现象、找到资料，也能更清楚地判断 AI 给出的建议是否适合自己的电脑。

本章将从认识键盘与鼠标开始，逐步介绍操作系统的使用、文件管理、浏览器、搜索与软件下载、编辑器、基本终端操作、Git 与 AI 辅助学习，帮助你学习计算机的基本知识。

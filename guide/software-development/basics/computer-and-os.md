# 1.2 详细了解计算机与操作系统

> 本章将提供简单的计算机组成与各部件作用资料，帮助新同学简单了解计算机的浅层粗组成。

## 本节目标

1. **认识主要硬件**：CPU 负责执行指令，内存保存运行中的数据，硬盘或其他存储设备用于长期保存文件；了解显卡承担的图形与计算工作。先区分它们的用途。
2. **认识操作系统**：了解 Windows、MacOS 等不同桌面系统；理解操作系统管理硬件、文件和程序的基本作用。
3. **区分应用与进程**：安装好的应用与正在运行的程序是什么关系；认识任务管理器或活动监视器，了解 CPU、内存等占用信息。
4. **查阅设备信息**：系统名称和版本、处理器型号与架构、内存容量、可用存储空间。理解 x64、ARM64 等安装包标记需要与设备和系统兼容。

这一阶段重点是认识用途，尽可能对计算机形成浅层组成常识。计算机组成与操作系统原理会在后续专业基础学习中展开。

# 软件开发

软件开发不只是编写代码，还包括理解需求、设计方案、验证结果和持续维护。本指南按共同基础、开发方向和项目实践分章，帮助你逐步建立完整的开发能力。

建议先学习共同基础，再选择一个主要方向，最后通过完整项目把知识串起来。不必一开始就追逐所有技术栈。

## 开始学习

[第一章：基础入门](/guide/software-development/basics/) 从认识键盘与鼠标开始，依次介绍电脑与操作系统、文件、浏览器与软件下载、编辑器与终端、Git，以及 AI 辅助学习。

每一节按「为什么学 → 学什么 → 去哪里学 → 下一步」组织，提供知识点顺序与学习资料。资料优先选择官方站点的简体中文文档，并标明建议阅读的部分。已经熟悉的内容可以跳过。

后续编程与项目章节将逐步补充。
